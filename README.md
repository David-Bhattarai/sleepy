# AURA Mental Health AI System

## 🚀 Quick Start

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Start Server:**
   ```bash
   python quick_start.py
   ```

3. **Access System:**
   - Open: http://127.0.0.1:5000
   - Sign up and start using AURA

## 🎯 Features

- 🤖 **AI Chatbot** - Therapeutic conversations
- 😊 **Emotion Detection** - Real-time face analysis  
- 📊 **Mood Tracking** - Daily mental health monitoring
- 🎥 **Video Consultation** - Professional support
- 🔐 **Secure** - Private and encrypted

## 🔑 Optional: AI Features

For advanced AI features, get a free API key:
1. Go to: https://makersuite.google.com/app/apikey
2. Create `.env` file: `GEMINI_API_KEY=your_key_here`
3. Restart server

System works perfectly without API key too!

## 🎉 Enjoy!

Your complete mental health AI companion is ready to use.
