🔧 INSTALLATION STEPS:

1. Install Python Dependencies:
   cd sleepy
   pip install -r requirements.txt

2. Install Server Dependencies:
   cd server
   pip install -r requirements.txt

3. Required Python Packages:
   - Flask (web framework)
   - Flask-Login, Flask-Bcrypt, Flask-Cors (authentication)
   - deepface (emotion detection)
   - vaderSentiment (sentiment analysis)
   - scikit-learn (ML model)
   - numpy (numerical operations)
   - gunicorn (production server)

🚀 RUNNING THE PROJECT:

Option 1 - Development Mode:
   cd sleepy/server
   python app.py
   
   Server will start at: http://localhost:5000

Option 2 - Production Mode:
   cd sleepy/server
   gunicorn -w 4 -b 0.0.0.0:5000 app:app

Option 3 - Using provided script:
   cd sleepy
   bash run_in_codespace.sh

🚨 TROUBLESHOOTING:

1. Import Errors:
   - Ensure all dependencies are installed
   - Check Python version (3.7+)
   - Verify virtual environment activation

2. Model Loading Issues:
   - Run train_realistic_model.py first
   - Check intents.json file exists
   - Verify pickle file permissions

3. Database Errors:
   - Delete database.db and restart
   - Check SQLite installation
   - Verify file permissions

4. Port Issues:
   - Change port in app.py if 5000 is busy
   - Use different port: app.run(port=8080)
